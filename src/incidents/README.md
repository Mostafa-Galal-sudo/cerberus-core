# src/incidents/

Incident data model and timeline (Checkpoint 3, task C3-T03).

Planned files:
- `schema.py` — incident record: detection ref, evidence entries, agent
  reasoning summary, decision, action, outcome, timestamps (UTC)
- `timeline.py` — ordered event list per incident, consumed by the dashboard
  and the final case study

The chain of evidence documented here is what the Week-5 case study
(C5-T06) and the final report are built from.
